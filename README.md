# Advanced AI Medical Intelligence Platform

## Project Overview
The Advanced AI Medical Intelligence Platform is an AI-powered web application that detects Pneumonia from Chest X-ray images using Deep Learning. It provides prediction results, confidence score, image preview, prediction history, and REST APIs.

## Features
- Chest X-ray Image Upload
- Pneumonia Detection using CNN
- Prediction Confidence Score
- Image Preview
- SQLite Database
- Prediction History
- REST API
- Flask Web Application

## Technologies Used
- Python
- TensorFlow
- Flask
- SQLite
- NumPy
- Pillow
- HTML
- CSS
